# 一.必答问题

## 1.类和对象是什么关系？

类：是对象共同特征的描述

对象:真实存在的具体实例，可以使用对象来完成需要的一些功能

## 2.`this` 解决了什么问题？

成员变量：定义在class里面，方法的外面

局部变量：定义在方法里面

就近原则：程序语句离哪个近就使用哪个变量

`this`关键字可以规定这个位置的变量使用成员变量

```java
public class Student{
    private int age;
    public void method(){
        int age=10;
        system.out.println(this.age);//age使用成员变量age
    }
}
```

## 3.静态成员和实例成员有什么区别？

实例成员属于对象，每次创建一个对象就会有一个实例成员。在new之后才会存在，可以使用对象.成员进行访问。

静态成员属于类，整个类共享一份，在类加载时就已经存在，可以使用类名.成员访问或者对象名.成员，==静态成员不能使用this==



## 4.`final` 修饰变量、方法和类时分别意味着什么？

final修饰方法，类，变量

* 修饰方法：方法是最终方法，不能被重写
  * 一般当前方法是一种规则，不能被改变时可以使用final
* 修饰类：该类是最终类，不能被继承
* 修饰变量：叫做常量，只能被赋值一次

**细节**

final修饰的变量是基本类型：变量存储的数据值不能发生改变

final修饰的变量是引用类型：变量存储的地址值不能发生改变，对象内部可以改变

## 2.4 构造方法

作用：在创建对象的时候给成员变量进行赋值

**构造方法的格式**

```java
public class student{
	修饰符 类名(参数){
        方法体;
    }
}
```

方法名与类名相同，大小写也要一致

没有返回值类型，不写void

没有具体的返回值

==执行时机==

* 创建对象的时候由虚拟机调用，不能手动调用构造方法
* 每创建一次对象，就会调用一次构造方法

 空参构造只有虚拟机赋的初值

含参构造可以在初始化的时候直接赋值成员变量

```java
public class Student{
    private String name;
    private int age;
    
    public Student(){
        System.out.println("xxx");
    }
    public Student(String name,int age){
        this.name=name;
        this.age=age;
    }
}
```

## 2.7 Static关键字

static表示静态，是java中的一个修饰符，可以修饰成员方法，成员变量

**静态变量**

被static修饰的成员变量是静态变量 放在堆内存中的静态存储位置

静态变量随着类的加载而加载，优先于对象出现

==在堆内存中是共享的，多个对象可以使用同一个静态变量，谁需要用谁去拿==

**静态方法**

* 多用在测试类(用来检查其他类是否书写正确，含main方法）和工具类（帮我们做一些事情但不描述任何事物的类)中
* 类名见名知意
* 私有化构造方法
* 方法定义为静态

```java
public class ArrUtil {

    private ArrUtil() {}//私有化构造方法，防止其它类中创建对象，创建工具类的对象没有意义

    public static int getMax(...) {...}

    public static int getMin(...) {...}

    public static int getSum(...) {...}

    public static int getAvg(...) {...}
}
```

**static的注意事项**

* 静态方法中只能访问静态
* 非静态方法可以访问所有
* 静态方法中没有this关键字
